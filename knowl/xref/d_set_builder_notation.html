Definition 1.1.12. Set-builder notation.

Let \(A\) be a set, and let \(P\) be a property that elements of \(A\) either satisfy or do not satisfy. For an element \(a\in A\text{,}\) let \(P(a)\) denote the statement that \(a\) satisfies property \(P\text{.}\) The set of all elements of \(A\) that satisfy property \(P\) is denoted
\begin{equation*} \{a \in A \mid P(a) \}\text{.} \end{equation*}
