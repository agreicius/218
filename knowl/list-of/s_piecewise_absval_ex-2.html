Exercise 2.

Find all the real values of \(x\) that satisfy the following inequalities. Write your answer using interval notation or set builder notation.
  1. \(\displaystyle \left| 2x+1\right|\leq 3\)
    🔗
    🔗
  2. \(\displaystyle \left|3x-2\right|>4\)
    🔗
    🔗
  3. \(\displaystyle \left| 2x+1\right|\leq 0\)
    🔗
    🔗
  4. \(\displaystyle \left| 2x+1\right|< 0\)
    🔗
    🔗
  5. \(\displaystyle \left| 2x+1\right|\geq 0\)
    🔗
    🔗
  6. \(\displaystyle \left| 2x+1\right|>0\)
    🔗
    🔗
🔗
Solution.
  1. Note that you can use a sign chart to solve these exercises.
    \begin{equation*} \left| 2x+1\right|\leq 3 \end{equation*}
    \begin{equation*} -3<2x+1<3 \end{equation*}
    \begin{equation*} -4<2x<2 \end{equation*}
    \begin{equation*} -2<x<1 \end{equation*}
    Thus, the solution is the interval \((-2,1)\text{.}\)
    🔗
    🔗
  2. \begin{equation*} \left|3x-2\right|>4 \end{equation*}
    \begin{equation*} 3x-2>4 \text{ or }3x-2<-4 \end{equation*}
    \begin{equation*} 3x>6 \text{ or }3x<-2 \end{equation*}
    \begin{equation*} x>2 \text{ or }x<-\dfrac{2}{3} \end{equation*}
    Thus, the solution is \((-\infty,-\dfrac{2}{3})\cup(2,\infty)\)
    🔗
    🔗
  3. Note that there are no \(x\) such that \(|2x+1|<0\text{,}\) so we only need to solve the equation \(|2x+1|=0\text{.}\)
    \begin{equation*} |2x+1|=0 \end{equation*}
    \begin{equation*} 2x+1=0 \end{equation*}
    \begin{equation*} x=-\dfrac{1}{2} \end{equation*}
    Thus, the solution is the set \(\{-\dfrac{1}{2}\}\)
    🔗
    🔗
  4. Since there are no such \(x\) such that \(|2x+1|<0\text{,}\) the solution is \(\emptyset\text{.}\)
    🔗
    🔗
  5. Since \(|2x+1|\geq0\) for all \(x\text{,}\) the solution is \(\mathbb{R}\text{.}\)
    🔗
    🔗
  6. \(|2x+1|>0\) for all \(x\) except when \(|2x+1|=0\text{,}\) i.e., \(x\in\mathbb{R}\setminus \{-1/2\}=(-\infty,-1/2)\cup(-1/2,\infty)\text{.}\)
    🔗
    🔗
