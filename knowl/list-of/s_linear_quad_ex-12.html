Exercise 12.

Determine whether the following statements are true or false. Justify your reasoning.
  1. If a linear function has a negative \(x\)-intercept and a positive \(y\)-intercept, then its slope must be positive.
    🔗
    🔗
  2. If \(f(x)=ax+b\) and \(f(3)=f(7)\text{,}\) then the graph of \(f(x)\) is a horizontal line.
    🔗
    🔗
  3. If a quadratic function has a negative leading coefficient, then it has to have \(x\)-intercepts.
    🔗
    🔗
  4. The function \(f(x)=-2(x-3)^{2}+8\) has a minimum at \((3,8)\text{.}\)
    🔗
    🔗
  5. There exist two perpendicular lines with positive slopes.
    🔗
    🔗
  6. A vertical line has slope 0.
    🔗
    🔗
  7. The lines \(ax+y=b\) and \(ax-y=b\) are perpendicular for every \(a\in\mathbb{R}\setminus\{0\}\text{.}\)
    🔗
    🔗
  8. The lines \(ax+y=b\) and \(x-ay=b\) are perpendicular for every positive real number \(a\text{.}\)
    🔗
    🔗
🔗
Solution.
  1. True. Say the \(x\)-intercept is \((a,0)\) and the \(y\)-intercept is \((0,b)\text{.}\) Then the slope is \(-b/a\text{,}\) which is positive since \(a\) is negative and \(b\) is positive.
    🔗
    🔗
  2. True. \(f(3)=3a+b\) and \(f(7)=7a+b\text{,}\) which means \(3a+b=7a+b \iff -4a=0 \iff a=0\text{.}\) If the slope is 0, then the line is horizontal.
    🔗
    🔗
  3. False. The graph of a quadratic function with a negative leading coefficient is open downwards, but the whole graph can be below the \(x\)-axis and therefore, have no \(x\)-intercepts. See for example the following function.
    🔗
    🔗
  4. False. The vertex form implies that the vertex is at \((3,8)\text{,}\) however, the leading coefficient is \(-2<0\text{,}\) so the function has a maximum and not a minimum.
    🔗
    🔗
  5. False. If the lines have slopes \(m_{1}, m_{2}\text{,}\) then \(m_{1}\cdot m_{2}=-1\text{,}\) which is not possible if both \(m_{1}\) and \(m_{2}\) are positive.
    🔗
    🔗
  6. False. The slope of a line is only defined for non-vertical lines.
    🔗
    🔗
  7. False. The first line has slope \(-a\) and the second line has slope \(a\text{.}\) If the lines are perpendicular, then \(-a\cdot a=-1\text{,}\) which is true only for \(a=\pm1\) and not for all nonzero real numbers.
    🔗
    🔗
  8. True. The slope of the first line is \(-a\) and the slope of the second line is \(1/a\) (note that we have no issues with \(a=0\) since \(a\) is positive). Then \(-a\cdot \dfrac{1}{a}=-1\text{,}\) so the lines are perpendicular.
    🔗
    🔗
