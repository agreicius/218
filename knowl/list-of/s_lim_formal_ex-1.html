Exercise 1.

Use the \(\epsilon\)- \(\delta\) definition of a limit to show the following statements.
  1. \(\displaystyle \displaystyle{\lim_{x \to 3} (x-1)}=2\)
    🔗
    🔗
  2. \(\displaystyle \displaystyle{\lim_{x \to 0} (2x+1)}=1\)
    🔗
    🔗
  3. \(\displaystyle \displaystyle{\lim_{x \to 1} (-2x+1)}=-1\)
    🔗
    🔗
  4. \(\displaystyle \displaystyle{\lim_{x \to 2} \dfrac{x^2-4}{x-2}}=4\)
    🔗
    🔗
🔗
Solution.
  1. Using the notation \(\displaystyle{\lim_{x \to a} f(x)}=L\text{,}\) \(f(x)=x-1, a=3, L=2\text{.}\) We have
    \begin{equation*} |f(x)-2|<\epsilon \end{equation*}
    \begin{equation*} |(x-1)-2|<\epsilon \end{equation*}
    \begin{equation*} |x-3|<\epsilon \end{equation*}
    Thus, we take \(\delta=\epsilon\text{.}\) Hence, for all \(\epsilon>0\text{,}\) let \(\delta=\epsilon\text{.}\) We have
    \begin{equation*} 0<|x-1|<\epsilon \Rightarrow |(x-1)-2|<\epsilon, \end{equation*}
    which proves that \(\displaystyle{\lim_{x \to 3} (x-1)}=2\text{.}\)
    🔗
    🔗
  2. Using the notation \(\displaystyle{\lim_{x \to a} f(x)}=L\text{,}\) \(f(x)=2x+1, a=0, L=1\text{.}\) We have
    \begin{equation*} |f(x)-1|<\epsilon \end{equation*}
    \begin{equation*} |(2x+1)-1|<\epsilon \end{equation*}
    \begin{equation*} |2x|<\epsilon \end{equation*}
    \begin{equation*} |2||x|<\epsilon \end{equation*}
    \begin{equation*} 2|x|<\epsilon \end{equation*}
    \begin{equation*} |x|<\epsilon/2 \end{equation*}
    Thus, we take \(\delta=\epsilon/2\text{.}\) Hence, for all \(\epsilon>0\text{,}\) let \(\delta=\epsilon/2\text{.}\) We have
    \begin{equation*} 0<|x|<\epsilon/2 \Rightarrow |(2x+1)-1|<\epsilon, \end{equation*}
    which proves that \(\displaystyle{\lim_{x \to 0} (2x+1)}=1\text{.}\)
    🔗
    🔗
  3. Using the notation \(\displaystyle{\lim_{x \to a} f(x)}=L\text{,}\) \(f(x)=-2x+1, a=1, L=-1\text{.}\) We have
    \begin{equation*} |f(x)-(-1)|<\epsilon \end{equation*}
    \begin{equation*} |(-2x+1)-(-1)|<\epsilon \end{equation*}
    \begin{equation*} |-2x+2|<\epsilon \end{equation*}
    \begin{equation*} |-2(x-1)|<\epsilon \end{equation*}
    \begin{equation*} |-2||x-1|<\epsilon \end{equation*}
    \begin{equation*} 2|x-1|<\epsilon \end{equation*}
    \begin{equation*} |x-1|<\epsilon/2 \end{equation*}
    Thus, we take \(\delta=\epsilon/2\text{.}\) Hence, for all \(\epsilon>0\text{,}\) let \(\delta=\epsilon/2\text{.}\) We have
    \begin{equation*} 0<|x-1|<\epsilon/2 \Rightarrow |(-2x+1)-(-1)|<\epsilon, \end{equation*}
    which proves that \(\displaystyle{\lim_{x \to 1} (-2x+1)}=-1\text{.}\)
    🔗
    🔗
  4. Using the notation \(\displaystyle{\lim_{x \to a} f(x)}=L\text{,}\) \(f(x)=\dfrac{x^2-4}{x-2}, a=2, L=4\text{.}\) We have
    \begin{equation*} |f(x)-2|<\epsilon \end{equation*}
    \begin{equation*} \left|\dfrac{x^2-4}{x-2}-4\right|<\epsilon \end{equation*}
    \begin{equation*} \left|\dfrac{(x-2)(x+2)}{x-2}-4\right|<\epsilon \end{equation*}
    \begin{equation*} |x+2-4|<\epsilon \end{equation*}
    \begin{equation*} |x-2|<\epsilon \end{equation*}
    Thus, we take \(\delta=\epsilon\text{.}\) Hence, for all \(\epsilon>0\text{,}\) let \(\delta=\epsilon\text{.}\) We have
    \begin{equation*} 0<|x-2|<\epsilon \Rightarrow \left|\dfrac{x^2-4}{x-2}-4\right|<\epsilon, \end{equation*}
    which proves that \(\displaystyle{\lim_{x \to 2} \dfrac{x^2-4}{x-2}}=4\text{.}\)

    🔗
