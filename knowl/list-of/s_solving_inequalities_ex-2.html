Exercise 2.

Determine whether the following statements are true or false. Justify your reasoning.
🔗
  1. If \(a,b\in \mathbb{R}\) are such that \(a\leq b\text{,}\) then \(a^{2}\leq ab\text{.}\)
    🔗
    🔗
  2. If \(a,b\in \mathbb{R}\) are such that \(a\leq b\text{,}\) then \(a^{3}\leq 2a^{2}\text{.}\)
    🔗
    🔗
  3. If \(a,b\in \mathbb{R}\) are such that \(a< b\text{,}\) then \(a^{3}< a^{2}b\text{.}\)
    🔗
    🔗
  4. If \(a,b\in \mathbb{R}\setminus\{0\}\) are such that \(a< b\text{,}\) then \(\dfrac{1}{a}>\dfrac{1}{b}\text{.}\)
    🔗
    🔗
  5. If \(a,b\in \mathbb{R}\) are such that \(0<a< b\text{,}\) then \(\dfrac{1}{a}>\dfrac{1}{b}\text{.}\)
    🔗
    🔗
🔗
Solution.
  1. False. Multiplying both sides of an inequality by a negative number changes the sign. For example, take \(a=-1,b=1\text{.}\) Then \(a=-1\leq 1=b\text{,}\) but \(a^{2}=1>-1=ab\text{.}\)
    🔗
    🔗
  2. True. \(a^{2}\) is either positive or \(0\text{.}\) If \(a^{2}>0\text{,}\) multiplying both sides of the inequality by \(a^{2}\) will not change the sign. If \(a^{2}=0\text{,}\) i.e. \(a=0\text{,}\) then we get \(a^{3}=0\leq0=2a^{2}\) which is also true.
    🔗
    🔗
  3. False. If \(a=0, b=1\text{,}\) it is not true that \(a^{3}=0 < 0=a^{2}b\text{.}\)
    🔗
    🔗
  4. False. If \(a=-1, b=1\text{,}\) it is not true that \(\dfrac{1}{a}=-1 > 1=\dfrac{1}{b}\)
    🔗
    🔗
  5. True. If we multiply both sides of the inequality by \(ab>0\text{,}\) then we get a true statement \(b>a\text{.}\)
    🔗
    🔗
