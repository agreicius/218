Exercise 8.

Find the (implied) domain and the zeroes (if any) of the following functions.
  1. \(\displaystyle f(x)=x^{2}-x+2\)
    🔗
    🔗
  2. \(\displaystyle f(x)=\dfrac{x^2-x-2}{5}\)
    🔗
    🔗
  3. \(\displaystyle f(x)=\dfrac{x-2}{2x^2-3x+1}\)
    🔗
    🔗
  4. \(\displaystyle f(x)=\dfrac{x-2}{x^2-4}\)
    🔗
    🔗
  5. \(\displaystyle f(x)=\dfrac{x^2-1}{x^3-x^2+x-1}\)
    🔗
    🔗
  6. \(\displaystyle f(x)=\dfrac{x^2+1}{x^3-2x+1}\)
    🔗
    🔗
🔗
Solution.
  1. This is a polynomial function (quadratic, to be specific) and therefore, the domain is \(\mathbb{R}\text{.}\)
    🔗
    To find the zeroes, we have to solve the equation \(x^{2}-x+2=0\text{.}\) However, this equation has no real solutions, so the function has no zeroes.
    🔗
    🔗
  2. This is also a polynomial function and hence the domain is \(\mathbb{R}\text{.}\)
    🔗
    The zeroes are \(-1\) and \(2\text{,}\) obtained by solving the equation \(\dfrac{x^2-x-2}{5}=0\text{.}\)
    🔗
    🔗
  3. This is a rational function that is defined for all real numbers such that \(2x^{2}-3x+1\neq0\text{.}\) The solutions to this equation are \(x=1/2\) and \(x=1\) and hence, the domain of the function is \(\mathbb{R}\setminus \{1,\dfrac{1}{2}\}\text{.}\)
    🔗
    \(\dfrac{x-2}{2x^2-3x+1}=0\) whenever \(x-2=0\) or \(x=2\text{.}\) Therefore, the function has one zero \(2\text{.}\)
    🔗
    🔗
  4. \(x^{2}-4=0\) whenever \(x=\pm 2\text{.}\) Therefore, the domain of the function is \(\mathbb{R}\setminus \{-2,2\}\text{.}\)
    🔗
    \(\dfrac{x-2}{x^2-4}=0\) whenever \(x-2=0\) or \(x=2\text{.}\) However, \(2\) is not in the domain of the function, and therefore the function has no zeroes.
    🔗
    🔗
  5. \begin{equation*} x^{3}-x^{2}+x-1=0 \end{equation*}
    \begin{equation*} x^{2}(x-1)+(x-1)=0 \end{equation*}
    \begin{equation*} (x-1)(x^{2}+1)=0 \end{equation*}
    \begin{equation*} x=1 \end{equation*}
    since \(x^{2}+1\neq 0\) for any real number \(x\text{.}\) Therefore, the domain of the function is \(\mathbb{R}\setminus \{1\}\text{.}\)
    🔗
    \(x^{2}-1=0\) whenever \(x^{2}=1\) i.e., whenever \(x=\pm1\text{.}\) However, \(1\) is not in the domain of the function, and hence, the only zero of the function is \(-1\text{.}\)
    🔗
    🔗
  6. To find the domain, we need to solve the equation \(x^{3}-2x+1=0\text{.}\) First, notice that \(x=1\) is a solution. Then, using long division, we conclude that \(x^{3}-2x+1=(x-1)(x^{2}+x-1)\text{.}\) Solving \(x^{2}+x-1=0\text{,}\) we get \(x=\dfrac{-1\pm\sqrt{5}}{2}\text{.}\) Thus the domain of the function is \(\mathbb{R}\setminus \{1,\dfrac{-1\pm\sqrt{5}}{2}\}\text{.}\)
    🔗
    To find the zeroes, we need to solve \(\dfrac{x^2+1}{x^3-2x+1}=0\text{,}\) which is equivalent to \(x^{2}+1=0\text{.}\) This equation has no real solutions and hence, the function has no zeroes.
    🔗
    🔗
