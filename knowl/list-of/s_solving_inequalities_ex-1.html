Solution.
  1. \begin{equation*} 5x-3&>3x+1\\ 5x-2x&>1+3\\ 3x&>4\\ x&>\dfrac{4}{3} \end{equation*}
    The solution is \(\left(\dfrac{4}{3},\infty\right)\text{.}\)
    🔗
    🔗
  2. \begin{equation*} (x-2)^{2}&\leq (x+1)^{2}\\ x^{2}-4x+3&\leq x^{2}+2x+1\\ -4x-2x&\leq 1-4\\ -6x&\leq -3\\ x&\geq \dfrac{1}{2} \end{equation*}
    The solution is \(\left[\dfrac{1}{2},\infty\right]\text{.}\)
    🔗
    🔗
  3. We need to solve the inequality \(x^{2}-4x+3\leq 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) \geq 0\text{,}\) where \(g(x)=x^{2}-4x+3\text{.}\) The first step is to find the domain of \(g(x)\text{.}\) The domain of \(g(x)\) is \(\mathbb{R}\text{.}\) Next, we find the zeroes by solving the equation \(g(x)=0\text{.}\)
    🔗
    \begin{equation*} x^{2}-4x+3&=0\\ (x-1)(x-3)&=0\\ x=1 \text{ or }x&=3. \end{equation*}
    Both \(1\) and \(3\) are in the domain of \(g(x)\text{,}\) so they are both zeroes. Using this information, we can draw a sign chart.
    🔗
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-5,0) -- (5,0); \draw (-2.5,0) node[circle,blue,fill,inner sep=2pt]{}; \draw (1.5,0) node[circle,blue,fill,inner sep=2pt]{}; \node at (-2.5, .5) {1}; \node at (1.5, .5) {3};\node at (-5,.5) {$g\colon$}; \node at (-3.5,.5) {$+$}; \node at (-0.4,.5) {$-$}; \node at (3, .5) {$+$};\end{tikzpicture} \end{equation*}
    🔗
    Since we are trying to find all \(x\) such that \(x^{2}-4x+3\) is negative or equal to \(0\text{,}\) using the sign chart, the solution is \([1.3]\text{.}\)
    🔗
    🔗
  4. \begin{equation*} x(x-1)&>(x-1\dfrac{1}{2})^{2}\\ x^{2}-x&>x^{2}-x+\dfrac{1}{4}\\ 0&>\dfrac{1}{4}. \end{equation*}
    Since \(0>\dfrac{1}{4}\) is false for any \(x\text{,}\) there is no real solution to this inequality. We say that the solution is \(\emptyset\) (the empty set ).
    🔗
    🔗
  5. We need to solve the inequality \(3x^{2}+5x+7> 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) \geq 0\text{,}\) where \(g(x)=3x^{2}+5x+7\text{.}\) However, this equation has no real solutions, so \(g(x)\) is either positive everywhere or negative everywhere. We notice that for all \(x\text{,}\) \(g(x)>0\text{.}\) Hence, all real numbers satisfy this inequality, so the solution is \((-\infty,\infty)=\mathbb{R}\text{.}\)
    🔗
    🔗
  6. From the previous exercise, we notice there are no \(x\) such that \(3x^{2}+5x+7\leq 0\text{,}\) so the solution is \(\emptyset\text{.}\)
    🔗
    🔗
  7. We need to solve the inequality \(\dfrac{2x-1}{x+2}\geq 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) \geq 0\text{,}\) where \(g(x)=\dfrac{2x-1}{x+2}\text{.}\) The first step is to find the domain of \(g(x)\text{,}\) which is all real numbers such that \(x+2\neq0\text{.}\) Thus, the domain of \(g(x)\) is \((-\infty, -2) \cup (-2, \infty)\text{.}\) Next, we find the zeroes by solving the equation \(g(x)=0\text{.}\)
    🔗
    \begin{equation*} \dfrac{2x-1}{x+2}&=0\\ 2x-1&=0\\ x&=\dfrac{1}{2}. \end{equation*}
    \(\dfrac{1}{2}\) is in the domain of \(g(x)\text{,}\) so it is a zero. Using this information, we can draw a sign chart.
    🔗
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-5,0) -- (5,0); \draw (1.5,0) node[circle,blue,fill,inner sep=2pt]{}; \draw[blue, thick, fill=white] (-2.5,0) circle (2.5pt); \node at (-2.5, .5) {-2}; \node at (1.5, .5) {1/2};\node at (-5,.5) {$g\colon$}; \node at (-3.5,.5) {$+$}; \node at (-0.4,.5) {$-$}; \node at (3, .5) {$+$};\end{tikzpicture} \end{equation*}
    🔗
    Since we are trying to find all \(x\) such that \(\dfrac{2x-1}{x+2}\) is positive or equal to \(0\text{,}\) using the sign chart, we conclude that the solution is \((\infty, -2) \cup [1/2, \infty]\text{.}\)
    🔗
    🔗
  8. \begin{equation*} \dfrac{2x-1}{x+2}&\geq 2\\ \dfrac{2x-1}{x+2}- 2&\geq 0\\ \dfrac{2x-1-2x-4}{x+2}&\geq 0\\ \dfrac{-5}{x+2}&\geq 0 \end{equation*}
    We need to solve the inequality \(\dfrac{-5}{x+2}\geq 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) \geq 0\text{,}\) where \(g(x)=\dfrac{-5}{x+2}\text{.}\) The first step is to find the domain of \(g(x)\text{.}\) The domain of \(g(x)\) is \((-\infty, -2) \cup (-2, \infty)\text{.}\) Next, we find the zeroes by solving the equation \(g(x)=0\text{.}\)
    🔗
    \begin{equation*} \dfrac{-5}{x+2}&=0\\ -5&=0 \end{equation*}
    so this equation has no solutions, and hence \(g(x)\) has no zeroes. This does NOT mean we cannot solve the inequality.
    🔗
    We can still draw a sign chart.
    🔗
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-4,0) -- (0,0); \draw[blue, thick, fill=white] (-2,0) circle (2.5pt); \node at (-2, .5) {-2};\node at (-5,.5) {$g\colon$}; \node at (-3.5,.5) {$+$}; \node at (-0.5,.5) {$-$};\end{tikzpicture} \end{equation*}
    🔗
    Since we are trying to find all \(x\) such that \(\dfrac{-5}{x+2}\) is positive or equal to \(0\text{,}\) using the sign chart, we conclude that the solution is \((-\infty,-2)\text{.}\)
    🔗
    🔗
  9. We need to solve the inequality \((x+1)(2x-1)^{2}(2-x)< 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) < 0\text{,}\) where \(g(x)=(x+1)(2x-1)^{2}(2-x)\text{.}\) The first step is to find the domain of \(g(x)\text{.}\) The domain of \(g(x)\) is \(\mathbb{R}\text{.}\) Next, we find the zeroes by solving the equation \((x+1)(2x-1)^{2}(2-x)=0\text{.}\) The solutions are \(x=-1,x=\dfrac{1}{2},x=2\) and all three solutions are in the domain. We draw a sign chart.
    🔗
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-7,0) -- (3,0); \draw (-2,0) node[circle,blue,fill,inner sep=2pt]{}; \draw (-4.5,0) node[circle,blue,fill,inner sep=2pt]{}; \draw (0.5,0) node[circle,blue,fill,inner sep=2pt]{}; \node at (-2, .5) {1/2}; \node at (-4.5, .5) {$-1$}; \node at (0.5, .5) {2}; \node at (-7,.5) {$g\colon$}; \node at (-3.25,.5) {$+$}; \node at (-0.75,.5) {$+$}; \node at (1.75, .5) {$-$}; \node at (-5.75, .5) {$-$};\end{tikzpicture} \end{equation*}
    🔗
    Since we are trying to find all \(x\) such that \((x+1)(2x-1)^{2}(2-x)\) is negative, using the sign chart, we conclude that the solution is \((-\infty,-1)\cup (2,\infty)\text{.}\)
    🔗
    🔗
  10. We need to solve the inequality \(\dfrac{(x+1)(2x-1)^2}{2-x}\leq 0\text{.}\) In other words, we need to find all \(x\) such that \(g(x) \leq 0\text{,}\) where \(g(x)=\dfrac{(x+1)(2x-1)^2}{2-x}\text{.}\) The first step is to find the domain of \(g(x)\text{.}\) The domain of \(g(x)\) is \(\mathbb{R}\setminus \{2\}\text{.}\) Next, we find the zeroes by solving the equation \(\dfrac{(x+1)(2x-1)^2}{2-x}=0\text{.}\) The solutions are \(x=-1,x=\dfrac{1}{2}\) and both are in the domain. We draw a sign chart.
    🔗
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-7,0) -- (3,0); \draw (-2,0) node[circle,blue,fill,inner sep=2pt]{}; \draw (-4.5,0) node[circle,blue,fill,inner sep=2pt]{};\draw[blue, thick, fill=white] (0.5,0) circle (2.5pt); \node at (-2, .5) {1/2}; \node at (-4.5, .5) {$-1$}; \node at (0.5, .5) {2}; \node at (-7,.5) {$g\colon$}; \node at (-3.25,.5) {$+$}; \node at (-0.75,.5) {$+$}; \node at (1.75, .5) {$-$}; \node at (-5.75, .5) {$-$};\end{tikzpicture} \end{equation*}
    🔗
    Since we are trying to find all \(x\) such that \(\dfrac{(x+1)(2x-1)^2}{2-x}\leq 0\) is negative or 0, using the sign chart, we conclude that the solution is \((-\infty,-1]\cup (2,\infty)\text{.}\)
    🔗

  11. \begin{equation*} \dfrac{x^2+8x+7}{x-1}>2&\iff \dfrac{x^2+8x+7}{x-1}-2>0\\&\iff \dfrac{x^2+8x+7}{x-1}-\dfrac{2x-2}{x-1}>0\\&\iff \dfrac{x^2+6x+9}{x-1}>0\\&\iff \dfrac{(x+3)^2}{x-1}>0 \end{equation*}
    We can use a sign chart as previously to solve the inequality. However, notice that \((x+3)^{2}\geq 0\) for all \(x\in\mathbb{R}\text{,}\) so we only need to find the \(x\) such that \(x-1>0\) i.e., \(x>1\text{.}\) Thus, the solution is \((1,\infty)\text{.}\)
