Exercise 3.

Determine which of the following functions are quadratic. For those that are:
  • Find the vertex form.
    🔗
    🔗
  • Find the domain and range.
    🔗
    🔗
  • Find the \(x\) and \(y\)-intercepts (if any).
    🔗
    🔗
  • Find the intervals of monotonicity.
    🔗
    🔗
  • Find the minimum/maximum (if any).
    🔗
    🔗
  • Sketch the graph of the function by sketching the \(x\) and \(y\)-intercepts and the vertex.
    🔗
    🔗
  1. \(\displaystyle f(x)=2-3x+x^{2}\)
    🔗
    🔗
  2. \(\displaystyle f(x)=(x+2)^{2}-(x-2)^{2}\)
    🔗
    🔗
  3. \(\displaystyle f(x)=\dfrac{x^2-1}{x-1}\)
    🔗
    🔗
  4. \(\displaystyle f(x)=3x-(x+\dfrac{3}{2})^{2}\)
    🔗
    🔗
  5. \(\displaystyle f(x)=(x+1)^{3}-(x+1)(x^{2}-x+1)\)
    🔗
    🔗
🔗
Solution.
  1. The function is quadratic. To find the vertex form, we complete the square in the following way
    \begin{align*} x^{2}-3x+2\amp =x^{2}-3x+\left(\dfrac{-3}{2}\right)^{2}-\left(\dfrac{-3}{2}\right)^{2}+2\\ \amp= \left(x-\dfrac{3}{2}\right)^{2}-\dfrac{9}{4}+2\\ \amp=\left(x-\dfrac{3}{2}\right)^{2}-\dfrac{1}{4}\text{.} \end{align*}
    The domain of any quadratic function is \(\mathbb{R}\text{,}\) and the range is \(\left[-\dfrac{1}{4},\infty \right).\)
    🔗
    To find the \(x\)-intercepts, we solve the equation \(x^{2}-3x+2=0\text{,}\) which is equivalent to \((x-1)(x-2)=0\text{,}\) i.e., \(x=1, x=2\text{.}\) Thus, the function has two \(x\)-intercepts \((1,0)\) and \((2,0)\text{.}\) To find the \(y\)-intercept, we set \(x=0\) i.e. \(0^{2}-3\cdot 0+2=2\text{,}\) so the \(y\)-intercept is \((0,2)\text{.}\)
    🔗
    The function is decreasing on \((-\infty,\dfrac{3}{2})\) and it is increasing on \((\dfrac{3}{2},\infty)\text{.}\)
    🔗
    The function has a minimum at the point \(\left(\dfrac{3}{2},-\dfrac{1}{4}\right)\) and has no maximum.
    🔗
    🔗
  2. Simplifying, we get \(f(x)=(x^{2}+4x+4)-(x^{2}-4x+4)=8x\text{,}\) so the function is not quadratic (it is linear).
    🔗
    🔗
  3. Not quadratic (it is a rational function).
    🔗
    🔗
  4. Simplifying, we get \(f(x)=3x-(x^{2}+3x+\dfrac{9}{4})=-x^{2}-\dfrac{9}{4}\text{,}\) so the function is quadratic. The vertex form of the function is \(f(x)=-(x-0)^{2}-\dfrac{9}{4}\text{.}\)
    🔗
    The domain of any quadratic function is \(\mathbb{R}\text{,}\) and the range is \(\left( -\infty, -\dfrac{9}{4}\right]\text{.}\)
    🔗
    To find the \(x\)-intercept, we solve the equation \(-x^{2}-\dfrac{9}{4}=0\text{,}\) which is equivalent to \(x^{2}=-\dfrac{9}{4}\text{.}\) But this equation has no solutions and therefore there are no \(x\)-intercepts. To find the \(y\)-intercept, we set \(x=0\) i.e. \(-0^{2}-\dfrac{9}{4}=-\dfrac{9}{4}\text{,}\) so the \(y\)-intercept is \((0,-\dfrac{9}{4})\text{.}\)
    🔗
    The function is increasing on \((-\infty,0)\) and it is decreasing on \((0,\infty)\text{.}\)
    🔗
    The function has a maximum at the point \(\left(0,-\dfrac{9}{4}\right)\) and has no minimum.
    🔗
    🔗
  5. Simplifying, we get \(f(x)=(x^{3}+3x^{2}+3x+1)-(x^{3}+1)=3x^{2}+3x\text{,}\) so the function is quadratic.
    🔗
    To find the vertex form, we complete the square in the following way
    \begin{align*} 3x^{2}+3x \amp =3(x^{2}+x)\\ \amp =3(x^{2}+x+\left(\dfrac{1}{2}\right)^{2}-\left(\dfrac{1}{2}\right)^{2})\\ \amp =3(\left(x+\dfrac{1}{2}\right)^{2}-\dfrac{1}{4})\\ \amp =3\left(x+\dfrac{1}{2}\right)^{2}-\dfrac{3}{4}\\ \amp =3\left(x+\dfrac{1}{2}\right)^{2}-\dfrac{3}{4}\\ \amp=3(\left(x+\dfrac{1}{2}\right)^{2}-\dfrac{1}{4})\\ \amp=3(x^{2}+x+\dfrac{1}{4}-\dfrac{1}{4})\\ \amp=3(x^{2}+x)-\dfrac{3}{4}\\ \amp=3(x^{2}+x+\dfrac{1}{4}-\dfrac{1}{4})-\dfrac{3}{4}\\ \amp=3((x+\dfrac{1}{2})^{2}-\dfrac{1}{4})-\dfrac{3}{4}\\ \amp=3(x+\dfrac{1}{2})^{2}-\dfrac{3}{4}-\dfrac{3}{4}\\ \amp=3\left(x+\dfrac{1}{2}\right)^{2}-\dfrac{3}{4}\text{.} \end{align*}
    🔗
    The domain of any quadratic function is \(\mathbb{R}\text{,}\) and the range is \(\left[-\dfrac{3}{4},\infty \right).\)
    🔗
    To find the \(x\)-intercept, we solve the equation \(3x^{2}+3x=0\text{,}\) which is equivalent to \(3x(x+1)=0\text{,}\) i.e., \(x=0, x=-1\text{.}\) Thus, the function has two \(x\)-intercepts \((-1,0)\) and \((0,0)\text{.}\) To find the \(y\)-intercept, we set \(x=0\) i.e. \(3\cdot0^{2}+3\cdot 0=0\text{,}\) so the \(y\)-intercept is \((0,0)\text{.}\)
    🔗
    The function is decreasing on \((-\infty,-\dfrac{1}{2})\) and it is increasing on \((-\dfrac{1}{2},\infty)\text{.}\)
    🔗
    The function has a minimum at the point \(\left(-\dfrac{1}{2},-\dfrac{3}{4}\right)\) and has no maximum.
