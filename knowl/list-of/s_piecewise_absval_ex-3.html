Exercise 3.

Determine whether the following statements are true or false. Justify your reasoning.
  1. \(|a+b|=|a|+|b|\) for all real numbers \(a,b\text{.}\)
    🔗
    🔗
  2. \(|ab|=|a||b|\) for all real numbers \(a,b\text{.}\)
    🔗
    🔗
  3. \(\left|\dfrac{a}{b}\right|=\dfrac{|a|}{|b|}\) for all real numbers \(a,b\text{.}\)
    🔗
    🔗
  4. If \(x\) is a real number such that \(|x-2|<3\text{,}\) then \(|3x-6|<10\text{.}\)
    🔗
    🔗
  5. If \(x\) is a real number such that \(|3x-6|<10\text{,}\) then \(|x-2|<3\text{.}\)
    🔗
    🔗
🔗
Solution.
  1. False. For example, the equality is not true if \(a=-1, b=1\text{.}\)
    🔗
    🔗
  2. True.
    🔗
    🔗
  3. False. If \(b=0\text{,}\) neither side of the equality is defined.
    🔗
    🔗
  4. True. Multiply both sides of \(|x-2|<3\) by \(3\) to get \(3|x-2|<9\text{,}\) which is equivalent to \(|3x-6|<9\text{.}\) But \(9<10\text{,}\) so \(|3x-6|<10\)
    🔗
    🔗
  5. False. If we try to use the same idea as before and multiply by \(1/3\text{,}\) we get \(|x-2|<\dfrac{10}{3}\text{,}\) but \(\dfrac{10}{3}>3\text{.}\) Hence, any value of \(x\text{,}\) such that \(3<|x-2|<10/3\) will make this statement false. For example, if you take \(x=5.2\text{,}\) \(|3\cdot 5.2-6|<10\text{,}\) but \(|5.2-2|>3\text{.}\)
    🔗
    🔗
