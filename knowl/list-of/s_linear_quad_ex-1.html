Exercise 1.

Determine which of the following functions are linear. For those that are:
  • Find the \(x\) and \(y\)-intercepts (if any)
    🔗
    🔗
  • Determine whether they are increasing or decreasing
    🔗
    🔗
  • Find the \(x\) for which the function is positive/negative.
    🔗
    🔗
  • Find the minimum/maximum (if any).
    🔗
    🔗
  • Sketch the graph of the function.
    🔗
    🔗
  1. \(\displaystyle f(x)=-\dfrac{1}{2}x+2\)
    🔗
    🔗
  2. \(\displaystyle f(x)=-\dfrac{1}{2x}+2\)
    🔗
    🔗
  3. \(\displaystyle f(x)=(x+2)^{2}-(x-2)^{2}\)
    🔗
    🔗
  4. \(\displaystyle f(x)=-(x+1)(x-3)+x(x-2)\)
    🔗
    🔗
  5. \(\displaystyle f(x)=\dfrac{x^2-1}{x-1}\)
    🔗
    🔗
🔗
Solution.
  1. The function is linear.
    🔗
    To find the \(x\)-intercept, we need to solve the equation \(-\dfrac{1}{2}x+2=0\text{.}\) Solving the equation, we get \(x=4\text{,}\) so the \(x\)-intercept is \((4,0)\text{.}\)
    🔗
    To find the \(y\)-intercept, set \(x=0\text{.}\) We get \(y=2\text{,}\) so the \(y\)-intercept is \((0,2)\text{.}\)
    🔗
    Since the slope \(m=-\dfrac{1}{2}<0\text{,}\) the function is decreasing on \(\mathbb{R}\text{,}\) and hence, has no minimum/maximum.
    🔗
    To find the \(x\) for which the function is positive/negative, we need to solve the inequalities \(f(x)>0\) and \(f(x)<0\text{.}\) Note that it is enough to solve one of them.
    \begin{equation*} f(x)>0 \end{equation*}
    \begin{equation*} -\dfrac{1}{2}x+2>0 \end{equation*}
    \begin{equation*} -\dfrac{1}{2}x>-2 \end{equation*}
    \begin{equation*} x<4. \end{equation*}
    Therefore, the function is positive on \((-\infty,4)\) and negative on \((4,\infty)\text{.}\)
    🔗
    🔗
  2. Not linear.
    🔗
    🔗
  3. Simplifying, we get \(f(x)=(x^{2}+4x+4)-(x^{2}-4x+4)=8x\text{,}\) so the function is linear.
    🔗
    To find the \(x\)-intercept, we need to solve the equation \(8x=0\text{.}\) Solving the equation, we get \(x=0\text{,}\) so the \(x\)-intercept is \((0,0)\text{.}\)
    🔗
    To find the \(y\)-intercept, set \(x=0\text{.}\) We get \(y=0\text{,}\) so the \(y\)-intercept is \((0,0)\text{.}\)
    🔗
    Since the slope \(m=8>0\text{,}\) the function is increasing, and hence, has no minimum/maximum.
    🔗
    To find the \(x\) for which the function is positive/negative, we need to solve the inequalities \(f(x)>0\) and \(f(x)<0\text{.}\) Note that it is enough to solve one of them.
    \begin{equation*} f(x)>0 \end{equation*}
    \begin{equation*} 8x>0 \end{equation*}
    \begin{equation*} x>0. \end{equation*}
    🔗
    Therefore, the function is negative on \((-\infty,0)\) and positive on \((0,\infty)\text{.}\)
    🔗
    🔗
  4. Simplifying, we get \(f(x)=-(x^{2}-3x+x-3)+(x^{2}-2x)=-x^{2}+2x+3+x^{2}-2x=3\text{,}\) so the function is constant and, therefore, linear.
    🔗
    There is no \(x\)-intercept and the \(y\)-intercept is \((0,3)\text{.}\)
    🔗
    Since the function is constant, it is not increasing nor decreasing, and both the minimum and maximum are \(3\text{,}\) achieved at every \(x\in\mathbb{R}\text{.}\)
    🔗
    Since \(f(x)=3>0\text{,}\) the function is positive for all \(x\in\mathbb{R}\text{.}\)
    🔗
    🔗
  5. Not linear, the domain of this function is \(\mathbb{R}\setminus\{1\}\text{,}\) and the domain of all linear functions is an interval. (Even though when you simplify the expression algebraically, you get \(\dfrac{(x-1)(x+1)}{x-1}=x+1\text{.}\))
