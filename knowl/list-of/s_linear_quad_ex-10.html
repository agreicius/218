Exercise 10.

Find the value of \(k\) for which the line \(2x-ky=1\)
  1. passes through the point \((1,-2)\text{.}\)
    🔗
    🔗
  2. passes through the point \((1,0)\text{.}\)
    🔗
    🔗
  3. passes through the point \((\dfrac{1}{2},0)\text{.}\)
    🔗
    🔗
  4. is parallel to the line \(2x+y=1\text{.}\)
    🔗
    🔗
  5. is perpendicular to the line \(2x+y=1\text{.}\)
    🔗
    🔗
  6. is parallel to the line passing through the points \((1,-1)\) and \((3,-2)\text{.}\)
    🔗
    🔗
  7. is perpendicular to the line \(y=2\text{.}\)
    🔗
    🔗
  8. whose nonzero coordinates of the \(x\)- and \(y\)-intercepts are equal.
    🔗
    🔗
🔗
Solution.
  1. If a line passes through a point, then the coordinates of the point satisfy the equation of the line. Hence, we have \(2\cdot1-k\cdot(-2)=1\text{.}\) Solving for \(k\text{,}\) we get \(k=-\dfrac{1}{2}\text{.}\)
    🔗
    🔗
  2. Similarly to part (a), we have \(2\cdot 1-k\cdot 0=1\text{,}\) or \(2=1\text{.}\) This equation does not have any solutions ( \(2=1\) is not a true statement for any \(x\) ), so there is no \(k\) that satisfies this condition.
    🔗
    🔗
  3. In this case, we get the equation \(2\cdot\dfrac{1}{2}-k\cdot0=1\text{,}\) or \(1=1\text{.}\) Any real number \(k \in \mathbb{R}\) satisfies this equation.
    🔗
    🔗
  4. Transforming the equations to the form \(y=mx+b\text{,}\) we notice that the slope of the line \(2x+y=1\) is \(-2\) and the slope of the line \(2x-ky=1\) is \(\dfrac{2}{k}\) whenever \(k\neq0\text{.}\) Since the lines are parallel, the slopes are equal \(-2=\dfrac{2}{k}\) and hence \(k=-1\text{.}\)
    🔗
    🔗
  5. If two lines with slopes \(m_{1}\neq 0\) and \(m_{2}\neq 0\) are perpendicular, then \(m_{1}\cdot m_{2}=-1\text{.}\) The slope of \(2x+y=1\) is \(-2\) and hence \(-2\cdot\dfrac{2}{k}=-1\text{.}\) Solving this equation, we get \(k=4\text{.}\)
    🔗
    🔗
  6. The slope of this line is \(m=\dfrac{-2-(-1)}{3-1}=-\dfrac{1}{2}\text{.}\) Hence, \(-\dfrac{1}{2}=\dfrac{2}{k}\) and \(k=-4\text{.}\)
    🔗
    🔗
  7. Since this line has slope \(0\text{,}\) we cannot use the equation from part (e). However, lines with slope \(0\) are horizontal, so any line perpendicular to it has to be vertical. Thus, we need to find a \(k\) for which \(2x-ky=1\) is vertical. This happens when \(k=0\text{.}\)
    🔗
    🔗
  8. The \(x\)-intercept is obtained by setting \(y=0\text{.}\) Hence, \(2x=1\) and \(x=\dfrac{1}{2}\text{.}\) The \(y\)-intercept is obtained by setting \(x=0\text{.}\) Hence, \(-ky=1\) and \(y=-\dfrac{1}{k}\text{,}\) provided \(k\neq 0\) (note that when \(k=0\text{,}\) the line is horizontal so it has no \(y\)-intercept).
    🔗
    Since the intercepts are equal, we set \(\dfrac{1}{2}=-\dfrac{1}{k}\text{,}\) so \(k=-2\text{.}\)
    🔗
    🔗
