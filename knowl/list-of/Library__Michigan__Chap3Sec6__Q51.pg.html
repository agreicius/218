Let \((x_0, y_0) = (2, 5)\) and \((x_1, y_1) = (2.2, 5.5)\text{.}\) Use the following graph of the function \(f\) to find the indicated derivatives.

Solution.
Since the point \((2,5)\) is on the curve, we know \(f(2)=5\text{.}\) The point \((2.2,5.5)\) is on the tangent line, so
\begin{equation*} \hbox{Slope of tangent} = \frac{5.5-5}{2.2-2} = \frac{0.5}{0.2} = 2.5. \end{equation*}
Thus, \(f'(2)=2.5\text{.}\)
🔗
By the chain rule
\begin{equation*} h'(2) = 2(f(2))\cdot f'(2) =2\cdot 5\cdot 2.5 = 25. \end{equation*}
🔗
Because \(g(x)\) is the inverse function of \(f\text{,}\) we know that \(g(5) = 2\text{.}\) Then note that \(f(g(x)) = f(f^{-1}(x)) = x\text{,}\) so \(f(g(x)) = x\text{.}\) Differentiating both sides of the equation, \(f'(g(x))\cdot g'(x) = 1\text{,}\) so \(g'(x) = \frac{1}{f'(g(x))}\text{.}\) Thus \(g'(5) = \frac{1}{f'(g(5))} = \frac{1}{f'(2)} = \frac1{2.5}\text{.}\)
