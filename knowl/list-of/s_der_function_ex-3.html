Exercise 3.

Compute the first derivatives of the following functions.
  1. \(\displaystyle f(x)=(2x+1)\sqrt{x}+\dfrac{1}{x}\)
    🔗
    🔗
  2. \(\displaystyle f(x)=\dfrac{2x-1}{x^2-1}\)
    🔗
    🔗
  3. \(\displaystyle f(x)=\dfrac{(x^{2}-1)^2}{x+2}\)
    🔗
    🔗
  4. \(\displaystyle f(x)=\dfrac{1}{(2x^{2}+3x-1)^{2025}}\)
    🔗
    🔗
  5. \(\displaystyle f(x)=(x-1)^{2}\sqrt{2x^{2}+1}\)
    🔗
    🔗
  6. \(\displaystyle f(x)=[(2x+1)^{4}-\sqrt{x}]^{3}\)
    🔗
    🔗
  7. \(\displaystyle f(x)=\sqrt{x^{2}+1+\sqrt{x^2+1}}\)
    🔗
    🔗
  8. \(\displaystyle f(x)=\sqrt{\dfrac{x^2}{\sqrt{x^{2}+1}}}\)
    🔗
    🔗
🔗
Solution.
  1. \begin{equation*} f'(x)&=(2x+1)'\sqrt{x}+(2x+1)\cdot \sqrt{x}'\\&= 2\sqrt{x}+(2x+1)\dfrac{1}{2}x^{1/2-1}\\&=2\sqrt{x}+\dfrac{2x+1}{2\sqrt{x}} \end{equation*}
    🔗
  2. \begin{equation*} f'(x))&=\dfrac{(2x-1)'(x^2-1)-(2x-1)(x^2-1)'}{(x^2-1)^2}\\&=\dfrac{2(x^2-1)-(2x-1)\cdot 2x}{(x^2-1)^2}\\&=\dfrac{2x^2-2-4x^2+2x}{(x^2-1)^2}\\&=\dfrac{-2x^2+2x-2}{(x^2-1)^2} \end{equation*}
    🔗
  3. \begin{equation*} f'(x)&=\frac{(x+2)[(x^{2}-1)^{2}]'-(x^{2}-1)^{2}(x+2)'}{(x+2)^{2}}\\&=\frac{(x+2)2(x^{2}-1)(x^{2}-1)'-(x^{2}-1)^{2}\cdot 1}{(x+2)^{2}}\\&=\frac{4x(x^{2}-1)(x+2)-(x^{2}-1)^{2}}{(x+2)^{2}}\\&=\frac{(x^{2}-1)\left[4x(x+2)-(x^{2}-1)\right]}{(x+2)^{2}}\\&=\frac{(x^{2}-1)(3x^{2}+8x+1)}{(x+2)^{2}} \end{equation*}
    🔗
  4. \(f(x)=(2x^{2}+3x-1)^{-2025}\text{,}\) so
    🔗
    \begin{equation*} f'(x)&=-2025(2x^{2}+3x-1)^{-2025-1}(2x^{2}+3x-1)'\\&=-2025(2x^{2}+3x-1)^{-2026}(4x+3)\\&=-\dfrac{2025(4x+3)}{(2x^2+3x-1)^{2026}} \end{equation*}
    🔗
  5. \(f(x)=(x-1)^{2}(2x^{2}+1)^{\frac{1}{2}}\text{,}\) so
    🔗
    \begin{equation*} f'(x)&=[(x-1)^{2}]'(2x^{2}+1)^{\frac{1}{2}}+(x-1)^{2}[(2x^{2}+1)^{\frac{1}{2}}]'\\&=2(x-1)^{2-1}(x-1)'(2x^{2}+1)^{\frac{1}{2}}+(x-1)^{2}\cdot \dfrac{1}{2}(2x^{2}+1)^{\frac{1}{2}-1}(2x^{2}+1)'\\&=2(x-1)\sqrt{2x^{2}+1}+\dfrac{2x(x-1)^2}{\sqrt{2x^{2}+1}} \end{equation*}
    🔗
  6. \begin{equation*} f'(x)&=3[(2x+1)^{4}-x^{\frac{1}{2}}]^{3-1}[(2x+1)^{4}-x^{\frac{1}{2}}]'\\&=3[(2x+1)^{4}-x^{\frac{1}{2}}]^{2}[4(2x+1)^{4-1}(2x+1)'-\dfrac{1}{2}x^{\frac{1}{2}-1}]\\&=3[(2x+1)^{4}-\sqrt{x}]^{2}[8(2x+1)^{3}-\dfrac{1}{2\sqrt{x}}] \end{equation*}
    🔗
  7. \(f(x)=(x^{2}+1+(x^{2}+1)^{\frac{1}{2}})^{\frac{1}{2}}\text{,}\) so
    🔗
    \begin{equation*} f'(x)&=\dfrac{1}{2}(x^{2}+1+(x^{2}+1)^{\frac{1}{2}})^{\frac{1}{2}-1}(x^{2}+1+(x^{2}+1)^{\frac{1}{2}})'\\&=\dfrac{1}{2}(x^{2}+1+(x^{2}+1)^{\frac{1}{2}})^{-\frac{1}{2}}(2x+\dfrac{1}{2}(x^{2}+1)^{\frac{1}{2}-1}(x^{2}+1)')\\&=\dfrac{1}{2}((x^{2}+1+(x^{2}+1)^{\frac{1}{2}})^{-\frac{1}{2}})(2x+x(x^{2}+1)^{-\frac{1}{2}}) \end{equation*}
    🔗
  8. \(f(x)=\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)^{\frac{1}{2}}\text{,}\) so
    🔗
    \begin{equation*} f'(x)&=\dfrac{1}{2}\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)^{\frac{1}{2}-1}\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)'\\&=\dfrac{1}{2}\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)^{-\frac{1}{2}}\dfrac{(x^2)'(x^2+1)^{\frac{1}{2}}-x^2[(x^2+1)^{\frac{1}{2}}]'}{x^2+1}\\&=\dfrac{1}{2}\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)^{-\frac{1}{2}}\dfrac{2x(x^2+1)^{\frac{1}{2}}-x^2\cdot \frac{1}{2}(x^2+1)^{\frac{1}{2}-1}(x^2+1)'}{x^2+1}\\&=\dfrac{1}{2}\left(\dfrac{x^2}{(x^2+1)^{\frac{1}{2}}}\right)^{-\frac{1}{2}}\dfrac{2x(x^2+1)^{\frac{1}{2}}-x^3(x^2+1)^{-\frac{1}{2}}}{x^2+1} \end{equation*}
    You can also write \(f(x)\) as \(f(x)=x(x^{2}+1)^{-\frac{1}{4}}\) and go from there.
