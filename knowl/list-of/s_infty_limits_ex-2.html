Exercise 2.

Find the horizontal and vertical asymptotes (if any) of the following functions. Use limits to justify your answers.
🔗
  1. \(\displaystyle f(x)=\dfrac{2x^2}{x^2-1}\)
    🔗
    🔗
  2. \(\displaystyle f(x)=\dfrac{x^2-4}{x-2}\)
    🔗
    🔗
  3. \(\displaystyle f(x)=\dfrac{x}{\sqrt{x^{2}-4}}\)
    🔗
    🔗
🔗
Solution.
  1. \(\displaystyle{\lim_{x\to\infty} \dfrac{2x^2}{x^2-1}}=2\text{,}\) so the function has a horizontal asymptote \(y=2\text{.}\) Since \(\displaystyle{\lim_{x\to-\infty} \dfrac{2x^2}{x^2-1}}=2\text{,}\) that is the only horizontal asymptote.
    🔗
    We test for vertical asymptotes at the points where \(x^{2}-1=0\) i.e., at \(x=\pm 1\text{.}\)
    🔗
    \(\displaystyle{\lim_{x\to1^-} \dfrac{2x^2}{x^2-1}}=-\infty\) and this is enough to conclude that the function has a vertical asymptote \(x=1\text{.}\)
    🔗
    \(\displaystyle{\lim_{x\to -1^-} \dfrac{2x^2}{x^2-1}}=\infty\) and this is enough to conclude that the function has a vertical asymptote \(x=-1\text{.}\)
    🔗
    🔗
  2. \(\displaystyle{\lim_{x\to\infty} \dfrac{x^2-4}{x-2}}=\infty\) and \(\displaystyle{\lim_{x\to-\infty} \dfrac{x^2-4}{x-2}}=-\infty\text{,}\) so the function has no horizontal asymptotes.
    🔗
    We test for vertical asymptotes at the points where \(x-2=0\) i.e., at \(x=2\text{.}\)
    🔗
    \(\displaystyle{\lim_{x\to2^-} \dfrac{x^2-4}{x-2}}=\displaystyle{\lim_{x\to2^+} \dfrac{x^2-4}{x-2}}=4\text{,}\) so the function has no vertical asymptotes.
    🔗
    🔗
  3. \(\displaystyle{\lim_{x\to\infty} \dfrac{x}{\sqrt{x^{2}-4}}}=1\) and \(\displaystyle{\lim_{x\to-\infty} \dfrac{x}{\sqrt{x^{2}-4}}}=-1\text{,}\) so the function has two horizontal asymptotes \(y=-1\) and \(y=1\text{.}\)
    🔗
    We test for vertical asymptotes at the points where \(\sqrt{x^{2}-4}=0\text{,}\) i.e., \(x=\pm 2\text{.}\)
    🔗
    Note that the function is not defined for \(x<2\) and \(x>-2\text{,}\) so we cannot find the left hand limit at 2 or the right hand limit at -2. Since
    🔗
    \(\displaystyle{\lim_{x\to-2^-} \dfrac{x}{\sqrt{x^{2}-4}}}=-\infty\) and \(\displaystyle{\lim_{x\to2^+} \dfrac{x}{\sqrt{x^{2}-4}}}=\infty\text{,}\) the function has 2 vertical asymptotes \(x=-2\) and \(x=2\text{.}\)
    🔗
    🔗
