Exercise 1.

Find the domain of the following algebraic functions.
🔗
  1. \(\displaystyle f(x)=\sqrt{|3-2x|-1}\)
    🔗
    🔗
  2. \(\displaystyle f(x)=\dfrac{(x-1)(x-4)}{\sqrt{x^{2}-4x+3}}\)
    🔗
    🔗
  3. \(\displaystyle f(x)=\dfrac{(x-1)^{3/2}-8}{x^2-6x+5}\)
    🔗
    🔗
Solution.
  1. To find the domain, we need to solve the inequality \(|3-2x|-1\geq 0\text{,}\) i.e. \(|3-2x|>1\text{.}\) Hence, \(3-2x>1\) or \(3-2x<-1\text{.}\) Solving these inequalities, we get \(x<1\) or \(x>2\text{.}\) Thus, the domain of the function is \((-\infty,1]\cup[2,\infty)\text{.}\)
    🔗
    To find the zeroes, we need to solve the equation \(\sqrt{|3-2x|-1}\text{,}\) i.e. \(|3-2x|-1=0\text{.}\)
    🔗
    \begin{equation*} |3-2x|-1=-&\iff |3-2x|=1\\&\iff 3-2x=1 \text{ or }3-2x=-1\\&\iff x=1 \text{ or }x=2 \end{equation*}
    Both 1 and 2 are in the domain, so both are zeroes of the function.
    🔗
    🔗
  2. To find the domain, we need to solve the inequality \(x^{2}-4x+3>0\text{.}\) Using a sign chart,
    \begin{equation*} \begin{tikzpicture}[scale=1]\draw[->] (-5,0) -- (5,0); \draw (-2.5,0) node[circle,blue,fill,inner sep=2pt]{}; \draw (1.5,0) node[circle,blue,fill,inner sep=2pt]{}; \node at (-2.5, .5) {1}; \node at (1.5, .5) {3};\node at (-3.5,.5) {$+$}; \node at (-0.4,.5) {$-$}; \node at (3, .5) {$+$};\end{tikzpicture} \end{equation*}
    we conclude that the domain is \((-\infty,1)\cup(3,\infty)\text{.}\)
    🔗
    To find the zeroes, we need to solve the equation \(f(x)=\dfrac{(x-1)(x-4)}{\sqrt{x^{2}-4x+3}}\text{,}\) i.e., \((x-1)(x-4)=0\iff x=1 \text{ or }x=4\text{.}\) But 1 is not in the domain of the function, so the only zero is 4.
    🔗
    🔗
  3. The domain of the function is all \(x\) such that \(x-1\geq 0\iff x\geq 1\) and such that \(x^{2}-6x+5\neq 0\text{,}\) i.e. \((1,5)\cup(5,\infty)\text{.}\)
    🔗
    To find the zeroes, we need to solve the equation \(\dfrac{(x-1)^{3/2}-8}{x^2-6x+5}=0\text{,}\) i.e., \((x-1)^{3/2}-8=0\text{.}\)
    🔗
    \begin{equation*} (x-1)^{3/2}-8=0&\iff (x-1)^{3/2}=8\\&\iff x-1=8^{2/3}\\&\iff x-1=4\\&\iff x=5 \end{equation*}
    But 5 is not in the domain of the function, so the function has no zeroes.
    🔗
    🔗
